# 125. Valid Palindrome

## Problem

Given a string, determine whether it is a palindrome,
considering only alphanumeric characters and ignoring case.

## Examples

- "A man, a plan, a canal: Panama" → True
- "race a car" → False

## Approach 1 — Preprocessing

### Idea

First remove all non-alphanumeric characters and convert
the string to lowercase. Then compare characters from the
two ends toward the center.

### Complexity

- Time: O(n)
- Space: O(n)
